## 6. 关键坑与教训（已沉淀到 docs/references/）

1. **坑 1（踩过两次）**：`PatchAll` 只应用「类级带 `[HarmonyPatch]`」的类型；方法级-only 的类被**静默跳过**，无任何报错。已通过任务 1.1 工具全量扫描 + 任务 1.2 启动自检双保险。
2. **坑 2**：拦截原实现绝不用 `ref bool __runOriginal`（本游戏内置 Harmony 2.4.2 会生成 `InvalidProgramException` → PatchAll 整体崩溃）；用 `return false` + `ref Task<T> __result` 模式。
3. **排查流程**：日志 `%APPDATA%\SlayTheSpire2\logs\godot.log`，grep `marker=` 确认版本、grep `启动自检` 确认补丁完整性；用 `log_timeline.py` / `log_parser.py`（pain/tools）浓缩时间线。
